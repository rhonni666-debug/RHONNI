PROJETO:
DIGITAL TWIN RAS — LITOPENAEUS VANNAMEI

Crie uma aplicação web profissional para monitoramento, simulação,
dimensionamento e operação assistida de um sistema RAS destinado à criação
de Litopenaeus vannamei, cobrindo:

Náuplio
→ Zoea
→ Mysis
→ Pós-larva
→ Berçário
→ Pré-engorda
→ Engorda
→ Despesca

O sistema deve funcionar como um GÊMEO DIGITAL.

Isso significa manter dois estados simultâneos:

1. SISTEMA REAL
   Dados efetivamente medidos pelo produtor.

2. SISTEMA VIRTUAL
   Estado calculado e previsto matematicamente.

O sistema deve comparar continuamente:

REAL
versus
MODELO

e recalibrar progressivamente os parâmetros matemáticos usando os dados
reais coletados.

Ele deverá aprender, com incerteza explícita:

quanto TAN o MBBR processa
quanto tempo leva para recuperar após mudança de salinidade
quanto a temperatura afeta o sistema
quanto a alimentação gera de carga

qual crescimento é normalmente obtido
qual FCR é normalmente obtido
qual margem operacional é segura

O modelo deverá ficar progressivamente mais personalizado com dados reais,
sem substituir medições por previsões.
